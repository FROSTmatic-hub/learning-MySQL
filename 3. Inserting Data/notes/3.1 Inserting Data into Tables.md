# How to Insert Data into Tables in MySQL?
- After creating a table, we can insert data(rows) using the command:
```sql
INSERT INTO table_name (column1, column2)
VALUES (value1, value2);
```
- For Example:
```sql
INSERT INTO pet_shop (name, age)
VALUES ('Mellow', 12);
```
> It is good practice to use ('') when adding values of VARCHAR in SQL, as using ("") can get you an error in other RDBMS.
> The order of the column matters when you are inserting data. We should be careful on what column we are inserting our data in.
