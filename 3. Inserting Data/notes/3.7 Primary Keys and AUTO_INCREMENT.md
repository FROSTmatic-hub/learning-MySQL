# What is AUTO_INCREMENT and How it is used with PRIMARY KEY?
- Firstly, There are two ways to declare a column as a primary key:
```sql
cat_id INT PRIMARY KEY
```
- Or we can use:
```sql
cat_id INT,
PRIMARY KEY (cat_id)
```
- Both forms make cat_id a primary key.
## Using AUTO_INCREMENT
- Use AUTO_INCREMENT to have MySQL assign each new row a new ID, usually starting at 1:
```sql
CREATE TABLE pet_shop (
    cat_id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50),
    age INT
);
```
- With `AUTO_INCREMENT`, MySQL assigns the ID automatically. 
- Each row gets a different ID, even if other values are identical.
