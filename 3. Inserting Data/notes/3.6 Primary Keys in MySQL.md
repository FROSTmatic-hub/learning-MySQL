- Rows can have identical values in their other columns, which makes them hard to tell apart. 
- A primary key gives each row a unique identifier.
- For Example: 
```sql
CREATE TABLE pet_shop (
    cat_id INT NOT NULL PRIMARY KEY,
    name VARCHAR(50),
    age INT
);
```
- Now, each inserted row needs a cat_id.
- If we try to reuse an existing ID, MySQL rejects that row with a duplicate key error.
