# How to Read Data in MySQL?
- We can already seen that for viewing the contents of our data, we use the command `SELECT`.
- For Example:
```sql
SELECT * FROM pet_shops; -- The '*' will give us all the columns from the pet_shop table
```
- We can also specify the columns we need, using the syntax:
```sql
SELECT <column1>, <column2>, FROM <tablename>;
```
