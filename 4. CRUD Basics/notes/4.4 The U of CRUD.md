# How to Update data in MySQL?
- To update an exisiting data, we can use the syntax:
```sql
UPDATE <tablename> SET <columnname> = <value> WHERE <condition>;
```
- For example:
```sql
UPDATE pet_shop SET name = 'Misty' WHERE breed = 'Tabby';
-- This will update all the animals who has breed 'Tabby' to 'Misty'
```
> Without a WHERE clause, MySQL updates every row in the table. That can be useful when you intend to change all rows, but use WHERE to target specific rows in most updates.
