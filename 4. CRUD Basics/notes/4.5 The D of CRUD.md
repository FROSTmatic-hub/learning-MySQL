# How to Delete data in MySQL?
- To Delete any existing data, we can use the syntax:
```sql
DELETE FROM <tablename> WHERE <condition>
```
- For Example:
```sql
DELETE FROM pet_shop WHERE age = 12;
-- All the animals who have a age 12 will be deleted.
```
## Important Note
- If we try the command:
```sql
DELETE FROM pet_shop;
-- This removes every row from petshop tabe, leaving the table structure in place. It does not delete the table.
```
