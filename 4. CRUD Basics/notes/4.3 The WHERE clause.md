# What is the WHERE clause in MySQL?
- The `WHERE` clause can be used to specify certain conditions when we are filtering our data using different CRUD operations.
- For Example:
```sql
SELECT * FROM pet_shop WHERE age = 4;
-- Here all the pets who are of 4 year old will be selected and printed out
```
- Another Example:
```sql
SELECT * FROM pet_shop WHERE name = 'Egg';
-- We can also filter by text but do note this is not case sensitive and entering 'Egg' or 'EGG' or 'eGG' will still give us the result.
```
