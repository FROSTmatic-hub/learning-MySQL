# What is SQL?
- **SQL** stands for **Structured Query Language**.
- It’s the language used to communicate with databases and manage their data.
- SQL queries can be used to:
    - Find data
    - Add new data
    - Update existing data
    - Delete data

# What is MySQL?
- **MySQL** is a **database management system (DBMS)**.
- It stores and manages data, and lets you interact with that data using SQL.
